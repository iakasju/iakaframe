# Validation de phase avant passage (phase gate)

Principe fondateur du modèle en cascade (stage-gate / tollgate). Le narratif de référence est le
cycle de vie en cascade.

**Politique.** Chaque **frontière de phase** est un **point de validation formel** : critères de
sortie vérifiés, livrable revu, **signature d'acceptation** apposée. Sans validation signée, la
phase suivante **ne démarre pas**. Le contrôle du projet vient de ces **portes successives** — pas
d'une boucle d'inspection empirique ni d'une auto-organisation. C'est le trait par lequel Waterfall
**rejoint** un frame à gates forts : chaque étape franchit un verrou explicite vers la suivante.

**Déclencheur.** à chaque revue de fin de phase (tollgate).
