# Montrer plutôt que dire

Principe du Design Thinking (d.school « Show don't tell »). Le narratif de référence est la
tradition centrée-humain.

**Politique.** On communique les idées en les rendant **tangibles** — croquis, storyboards,
prototypes, mises en scène — plutôt qu'en les **décrivant abstraitement**. Une idée qu'on peut
**voir, toucher ou vivre** se comprend, se partage et se **teste** ; une idée seulement décrite se
perd dans l'interprétation. Rendre visible, c'est déjà penser mieux.

**Déclencheur.** pour partager une idée, un concept, une intention.
