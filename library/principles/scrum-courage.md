# Valeur Scrum — Courage

Valeur fondamentale du *Scrum Guide 2020* (§ « Scrum Values »). Le narratif de référence est le
Scrum Guide.

**Politique.** Les membres de la Scrum Team ont le courage de faire ce qui est juste et de
travailler sur les problèmes difficiles ; dire la vérité sur l'avancement, remettre en cause ce qui
n'aide pas.

**Déclencheur.** décisions difficiles, transparence sur les problèmes.
