# Minimiser le temps total dans la boucle

Tenet du *Lean Startup* (Eric Ries, chap. « Steer »). Le narratif de référence est le livre de Ries.

**Politique.** L'objectif premier d'une startup n'est pas de produire vite, c'est de **minimiser le
temps total** d'un tour de la boucle **build → measure → learn**. La **vitesse d'apprentissage** est
l'avantage compétitif décisif : celui qui apprend le plus vite ce que veut le marché gagne. On
optimise donc le **cycle entier** (idée → construit → mesuré → appris → nouvelle idée), pas un maillon
isolé — accélérer le build sans accélérer la mesure ni l'apprentissage n'apporte rien.

**Déclencheur.** à la conception de chaque expérience — la question est « quel est le **chemin le
plus court** vers un apprentissage validé ? ».
