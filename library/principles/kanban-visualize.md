# Pratique 1 — Visualiser le flux

Première des **six pratiques générales** de la *Kanban Method*. Le narratif de référence est cette
littérature.

**Politique.** Rends **visibles** le travail et le **flux** : un **tableau** (*kanban board*) dont
les **colonnes** représentent les **étapes réelles** du process (pas un modèle idéalisé), les items
en cours, les **blocages**, et les **politiques** qui régissent chaque transition. Rendre le travail
invisible visible est le prérequis de tout le reste : **on ne peut améliorer que ce que l'on voit**.

**Déclencheur.** en permanence — le tableau est le **radiateur d'information** du système.
