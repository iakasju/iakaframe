# Valeur Scrum — Focus

Valeur fondamentale du *Scrum Guide 2020* (§ « Scrum Values »). Le narratif de référence est le
Scrum Guide.

**Politique.** Chacun se concentre sur le travail du Sprint et les objectifs de la Scrum Team ; le
**Sprint Goal** donne le focus, le WIP est limité, on finit avant de commencer.

**Déclencheur.** pendant le Sprint, arbitrage d'attention.
