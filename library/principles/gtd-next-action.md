# Prochaine action physique et visible

Principe opératoire central de GTD (*Getting Things Done*, David Allen). Le narratif de référence est
le livre.

**Politique.** Pour **tout item actionnable**, on définit **LA prochaine action physique et
visible** — le mouvement **concret** suivant (« appeler X », « rédiger le brouillon de… »), assez
précis pour être exécuté **sans avoir à re-réfléchir**. « Prochaine action » n'est pas un vague
« s'occuper de » : c'est le **premier pas physique**. Tout **projet** (résultat exigeant plus d'une
action) doit avoir **au moins une prochaine action** définie, sinon il est **bloqué** (cf.
`guardrails/next-action-defined`).

**Déclencheur.** à la clarification de tout item actionnable.
