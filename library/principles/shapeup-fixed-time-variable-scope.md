# Principe Shape Up — Temps fixe, périmètre variable

Principe fondateur de *Shape Up* (Ryan Singer, Basecamp, 2019). Le narratif de référence est le
livre *Shape Up*.

**Politique.** Le **temps est fixé** (l'appétit — par ex. 6 semaines) ; le **périmètre est la
variable** d'ajustement. Quand la réalité déborde du temps disponible, on ne **rallonge jamais** le
temps : on **réduit le périmètre**. La date ne bouge pas ; ce qui rentre dedans, si. C'est le
renversement exact du réflexe classique (« le périmètre est sacré, on repousse la date »).

**Déclencheur.** à chaque tension entre ce qui reste à faire et le temps restant.
