# Documentation exhaustive avant passage

Principe fondateur du modèle en cascade. Le narratif de référence est le cycle de vie en cascade.

**Politique.** Chaque phase produit un **livrable documentaire complet** (SRS pour les exigences,
SDD pour la conception, plan et rapport de test pour la vérification) qui devient le **contrat
d'entrée** de la phase suivante. On **ne passe pas** à la phase suivante sur un document partiel. La
documentation lourde en amont est **assumée** : la connaissance vit dans les **documents baselinés**,
opposables et traçables, pas dans les têtes ni dans le code seul.

**Déclencheur.** à la clôture de chaque phase (livrable documentaire).
