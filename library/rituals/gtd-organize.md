# Organize (rangement dans le système)

Troisième étape GTD (*Getting Things Done*, David Allen). Le narratif de référence est le livre.
Côté `solo`.

Le **rangement** de ce que Clarify a décidé, chacun **à sa place** dans le système de confiance, de
sorte que le bon élément soit **retrouvable au bon moment** : prochaines actions **par contexte**
(`principles/contexts`), **projets** listés avec issue (`principles/outcome-thinking`) et prochaine
action, **calendrier** réservé au *hard landscape* (ce qui DOIT arriver ce jour-là — pas une liste
de vœux), **Waiting For** pour le délégué, **Someday/Maybe** pour le non engagé, **référence** pour
le non actionnable utile. Organize ne décide rien de neuf : il **matérialise** la clarification et
maintient le système **digne de confiance** (`guardrails/trusted-system`). Souvent fondu avec
`rituals/clarify` dans le même passage d'inbox.
