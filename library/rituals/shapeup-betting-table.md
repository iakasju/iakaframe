# Betting Table (table des paris)

Rituel Shape Up (*Shape Up*, Ryan Singer, Basecamp, 2019 — part II « Betting »). Le narratif de
référence est le livre *Shape Up*. Côté `leadership`.

Une **réunion courte de dirigeants**, tenue **en cool-down**, où l'on **parie** — on ne planifie pas.
On examine les **pitchs façonnées** disponibles et l'on décide, pour le prochain cycle, **sur quoi
miser** : quoi, quel **appétit**, quelle équipe. C'est le **seul gate d'engagement** de Shape Up — un
vrai go/no-go — mais il est **à la frontière** entre les cycles, pas à l'intérieur. Trois disciplines
la caractérisent : (1) **repartir des pitchs** à chaque fois, sans dérouler un backlog ; (2) appliquer
le **circuit breaker** — un projet non fini n'est **pas prolongé par défaut**, il doit être re-façonné
et **re-parié explicitement** ; (3) **ne tenir aucun backlog**. Une fois les paris placés, la table se
**retire** : elle ne micro-gère pas les cycles.
