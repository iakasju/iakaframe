# Capture (collecte continue)

Première étape GTD (*Getting Things Done*, David Allen). Le narratif de référence est le livre.
Côté `solo`.

Le **réflexe permanent** : dès qu'une idée, une tâche ou un engagement accroche l'attention, le
**sortir de la tête** dans un **outil de collecte fiable** (inbox papier, note, boîte mail), **sans
encore décider** quoi en faire. Ce n'est pas un rendez-vous mais une **cadence continue** — le geste
doit être **sans friction** et les outils **ubiquitaires**. Objectif : que **rien** ne reste
« dans la tête » (`principles/capture-everything`, `principles/mind-like-water`). La capture
**alimente** le traitement (`rituals/clarify`) ; elle ne le remplace pas.
