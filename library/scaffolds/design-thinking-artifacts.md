# Scaffold artefacts Design Thinking

Échafaudage **NON DESTRUCTIF** des artefacts d'un défi de conception, alignés sur le **Double
Diamond** et les **cinq modes d.school**. On crée ce qui manque, on n'écrase rien. Le narratif de
référence est la tradition centrée-humain.

Chaque artefact matérialise une phase et **rend le travail visible** (§ `show-dont-tell`) — sans
trace tangible, l'itération se fait à l'aveugle :

| Phase (diamant) | Artefact | Rôle |
|---|---|---|
| Amont | `DESIGN-BRIEF.md` | le défi centré-utilisateur (pas une solution déguisée) |
| Discover (D1, divergent) | `research/` | matériaux d'empathie fidèles |
| Define (D1, convergent) | `problem/POINT-OF-VIEW.md` · `HOW-MIGHT-WE.md` | le bon problème, reformulé |
| Develop (D2, divergent) | `ideas/` | idées foisonnées puis concepts retenus |
| Develop (D2, convergent) | `prototypes/` | prototypes jetables, une itération par dossier |
| Deliver (D2, convergent) | `tests/` | preuves d'usage captées fidèlement |
| Boucle | `iterations/` | apprentissages + décision d'itérer ou d'aboutir |

Ces artefacts sont pensés pour l'**itération non-linéaire** : chaque tour laisse une trace datée dans
`iterations/`, si bien qu'on sait **pourquoi** on a rouvert tel diamant.
