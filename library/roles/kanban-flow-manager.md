# Flow Manager (Service Delivery Manager)

Rôle du référentiel Kanban, fidèle à la *Kanban Method* (David J. Anderson, *Essential Kanban
Condensed*, 2016) et au *Kanban Maturity Model*. Le narratif de référence est cette littérature ;
à charge d'une persona de le caster.

Comptable du **flux de travail à travers le système** — pas des personnes. Le Flow Manager (aussi
appelé **Service Delivery Manager**, SDM) veille à ce que le travail **s'écoule** : il rend le flux
visible, protège les **limites de WIP**, traque les items **bloqués** et **vieillissants**, anime
les cadences opérationnelles et suit les **métriques de flux** (lead time, throughput, âge du
travail en cours). Il **facilite le flux, il ne commande pas les gens** — « manage the work, not
the workers ».

> **Rôle FACULTATIF.** Kanban ne prescrit **aucun rôle obligatoire**. Le Flow Manager est l'un des
> **deux rôles reconnus** (l'autre étant le Service Request Manager), et il est **émergent, pas
> imposé** : on l'adopte quand le besoin de gérer le flux le justifie. Périmètre volontairement
> **léger** — c'est une **responsabilité de service**, pas une position hiérarchique.
