# Clarificateur — mode Clarify

**Mode fonctionnel**, pas un siège d'équipe. Deuxième étape GTD (*Getting Things Done*, David
Allen). Le narratif de référence est le livre.

En **mode Clarify**, le praticien **traite** ce qui a été capturé, item par item, en se posant **une
seule question** : « **Qu'est-ce que c'est ? Est-ce actionnable ?** »
- **Non actionnable** → poubelle, *someday/maybe*, ou référence.
- **Actionnable** → décider la **prochaine action physique** (`principles/next-action`). Si elle
  prend **moins de 2 minutes**, la faire **immédiatement** (`principles/two-minute-rule`) ; sinon,
  la déléguer ou la différer. Si l'item demande plusieurs actions, c'est un **projet** (on en note
  l'issue souhaitée — `principles/outcome-thinking`).

Clarifier, c'est **penser**, pas **faire** (`principles/separate-clarify-from-do`) : on décide ce
qu'un « truc » signifie **avant** de le ranger.

> **`scope: mode`.** Le Clarificateur est une **stance** du praticien unique, jamais une personne
> à part. Le workflow `gtd-flow` le donne pour acteur de sa phase `clarify`.
