Rôle

Démon local du portefeuille qui sert de passerelle « mode absence » humain↔agents : quand Stéphane est absent, un agent pose sa question sur le canal Discord du projet (sous son persona) et la réponse de Stéphane repart vers l'agent qui attendait (CLAUDE.md:24-28) V. Il sert aussi de saisie directe d'Odin via le canal #odin (lance une session Claude Code headless en lecture seule) et, sur une branche non fusionnée, de veilleur (horloge + sondes HTTP + alertes).
