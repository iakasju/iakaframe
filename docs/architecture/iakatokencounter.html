1. Rôle

Moniteur de consommation IA multi-comptes logé dans la barre système : il affiche une jauge de quota restant par compte (Claude, Codex), calculée à partir des journaux locaux des agents et de la statusline Claude Code, sans API distante (README.md:1-17, CLAUDE.md § « Ce qu'est ce projet »). Il porte son propre bus local : un broker MQTT embarqué (iakahub) sur lequel un démon de mesure publie des « codes » scalaires retenus, que le tray et d'autres logiciels peuvent lire (iakahub/README.md:1-8, specs/contrat-mqtt-conso.md § 0).

8. Points ouverts

  • Doc périmée : iakatc-daemon/README.md donne IAKATC_MQTT_HOST par défaut 192.168.2.11 et parle du « broker Mosquitto d'iakalogs », alors que le code est à 127.0.0.1 (iakatc-daemon/src/config.rs:13) V. De même CLAUDE.md du dépôt (backlog tokenizer/CLI itc count, remote Forgejo 192.168.2.11) et le README racine qui présente iakahub comme « connecteur optionnel vers le hub iaka » alors que c'est le broker embarqué V.
  • Capacité Tauri incohérente : capabilities/default.json:8-11 n'autorise que le sidecar binaries/iakatc-daemon, alors que le code spawne iakahub (src-tauri/src/lib.rs:126) V ; le spawn côté Rust n'est probablement pas soumis à l'ACL S.
  • Client ID partagé : si IAKATC_MQTT_CLIENT_ID est posé, tray et démon prennent le même identifiant (src-tauri/src/config.rs:41, iakatc-daemon/src/config.rs:47) → déconnexions croisées [S sur l'effet, V sur le code].
  • Plafond retenu 100/filtre : le filtre quota du tray franchit 100 topics au 8ᵉ compte IA (specs/contrat-mqtt-conso.md § 4) ; seul le resync toutes les 10 min répare un abonné tronqué [V doc + main.rs:28-43]. Tout nouvel abonné large (iakatokencounter/#, IakaAgentsMonitor…) est tronqué d'emblée (227 topics par tick mesurés, specs/etat-des-lieux.md) [V doc].
  • Broker anonyme sans auth sur loopback : tout processus local peut publier/effacer des retenus sous iakatokencounter/# [V config, S sur le risque].
  • Cycle de vie : le broker vit dans l'app tray ; si l'app est fermée, plus de broker pour les autres logiciels (IakaAgentsMonitor, Cockpit) [S, déduit de lib.rs:107-115]. Conflit de port possible avec un autre broker sur 1883 (fail-fast, pas d'auto-incrément) V.
  • Homonymie iakahub (crate Rust) / iakaHub (projet Node ~/work/iakaHub) : à lever dans la doc ; rôle réseau d'iakaHub Node non examiné ici S.
  • .../last non publié, quota Codex best-effort, used_tokens de quota = total provider (pas par compte) (iakatc-daemon/README.md § Limitations) [V doc].
  • Endpoint HTTP 4646 demandé par le portefeuille : non implémenté V.
